# Build provenance

The original engine.py prototype and basic UI existed before the event. They must not be presented as newly created during the hackathon.

The laboratory.py experiment graph, contextual replay UI and tests were implemented during the October 15 session. The runtime.py SQLite action/outcome loop, graph-based context retrieval, immutable observation/decision/version records, held-out comparisons and browser acceptance flow were implemented during the October 16 session.

The Groq local-tool agent, FalkorDB deployment-outcome tools, disposable HTTP canary toolbox and four-condition deployment evaluation were implemented during the October 16 session. Groq credentials are user-owned secrets and are not included in the repository.

The official brief in the read-only project sources requires the main FalkorDB implementation and features to be newly built within October 15–18. The event-built runtime is the main demonstrated feature; the older engine endpoints remain compatibility code. A local commit records the current snapshot, not a fabricated history of earlier changes. No timestamps are backdated. This disclosure does not replace the organizers' eligibility decision.
